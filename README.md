# Half Empty

2D pixel platformer-shooter. Тема — «наполовину пуст»: персонаж разделён на две половины (голова/тело), каждая — отдельная форма с собственным HP и возможностями. Ни одна половина не может выжить сама — приходится постоянно переключаться.

- **Unity**: `6000.3.14f1` (URP 2D)
- **Язык**: C# 9.0 / `netstandard2.1`
- **Архитектура**: Clean Architecture (Domain → Application → Infrastructure → Presentation)

---

## Игровой процесс

| Действие | Клавиша | Голова | Тело |
|---|---|---|---|
| Движение | `A` / `D` | Медленно | Быстро |
| Прыжок | `Space` | ❌ | ✅ |
| Рывок | `LCtrl` | ❌ | ✅ |
| Стрельба | `LMB` | Полный урон | Сниженный урон |
| Метка | `RMB` | ✅ | ❌ |
| Переключение формы | `LShift` | ✅ | ✅ |
| Пауза | `Esc` | ✅ | ✅ |

- У каждой формы отдельный HP; смерть любой формы → Game Over.
- **Голова**: полный обзор, можно метить врагов (метки видны сквозь туман).
- **Тело**: ограниченный обзор (внутренний круг — чётко, средний — приглушён, внешний — тьма), но можно бегать, прыгать и рывком.
- Парирование (`F` или `RMB`): отражает вражеский снаряд или убивает ближнего врага наповал.

## Быстрый старт

1. Откройте проект в **Unity 6000.3.14f1** (шаблон URP 2D).
2. Зайдите в `Assets/Scenes/Main.unity` и нажмите Play.
3. Если Input Actions не сгенерированы — включите **Input System** в Project Settings и перегенерируйте.
4. Подробнее в `SETUP.md` и `DisDoc.md`.
